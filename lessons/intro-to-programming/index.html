What is a script?

A script is just a list of instructions the computer carries out one after another, from top to bottom. Each line is a statement, and running the script means running every statement in order.

Example 
print("Hello, BINcyclopedia!")
print("This line runs second.")
name = "Ada"
print("Nice to meet you,", name)

Flow control: if / elif / else

  
A script can take different paths depending on a condition. An if block runs only when its condition is true, an elif checks another condition when the first was false, and else catches everything else.


  

    Example
    
temperature = 15

if temperature > 25:
    print("It's warm.")
elif temperature > 10:
    print("It's mild.")
else:
    print("It's cold.")

Loops: for and while

  
A loop repeats a block of code multiple times instead of copy-pasting it. A for loop repeats once per item in a sequence, like the numbers produced by range(1, 6). A while loop instead repeats for as long as a condition stays true.


  

    Example
    
total = 0
for n in range(1, 6):
    total = total + n
print("The total is", total)

Functions

  
A function packages up a set of instructions under a name, so you can reuse it without rewriting the code every time. You define it once with def, then call it by name whenever you need it, with different inputs.


  

    Example
    
def greet(name):
    return "Hello, " + name + "!"

print(greet("Ada"))
print(greet("Alan"))
