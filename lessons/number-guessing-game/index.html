The brief

Write a number-guessing game. The computer picks a secret whole number between 1 and 20. A player makes a series of guesses, and after each one the game says whether it was too low, too high, or correct, then reports how many guesses it took once it's correct.

To keep this checkable without live typing, you won't use input(). Instead you're given a ready-made list of guesses, as if a player had already typed them one at a time. Loop through the list and react to each guess.

Your code 
import random
random.seed(42)   # keeps the secret number the same every run, so your output is checkable
secret = random.randint(1, 20)

guesses = [10, 2, 5, 4]   # pretend a player typed these guesses, one at a time
attempts = 0

# Your job: loop through `guesses`. For each one:
#   - add 1 to attempts
#   - if the guess is too low, print "Too low"
#   - if the guess is too high, print "Too high"
#   - if the guess is correct, print "Correct! It took", attempts, "guesses."
#     and stop checking any further guesses

  
import random
random.seed(42)
secret = random.randint(1, 20)

guesses = [10, 2, 5, 4]
attempts = 0

for guess in guesses:
    attempts += 1
    if guess < secret:
        print("Too low")
    elif guess > secret:
        print("Too high")
    else:
        print("Correct! It took", attempts, "guesses.")
        break
